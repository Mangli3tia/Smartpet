# 🐾 智能宠物监督系统

基于 MQTT 的物联网监控系统，模拟温湿度传感器和摄像头抓拍，支持规则引擎自动报警，以及远程控制喂食器和空调，并提供实时 Web 仪表盘展示数据。

## ✨ 新增功能

- **真实图片抓拍**：摄像头发布端生成真实的随机彩色图片，并保存到 `static/` 目录，前端自动显示最新图片。
- **手动刷新摄像头**：点击“刷新摄像头”按钮，倒计时 10 秒后生成新图片并更新页面。
- **远程控制**：通过网页按钮控制喂食器、空调开关，订阅端执行模拟动作（可扩展为真实硬件），并反馈状态（成功/失败）。
- **状态反馈**：执行器完成动作后通过 MQTT 反馈状态，前端实时显示“喂食成功”、“空调已开启”等提示。

## 🔧 各模块功能

| 文件 | 功能 |
|------|------|
| config.py | 集中管理 MQTT Broker 地址、端口、传感器主题、控制主题、状态反馈主题、温度/湿度阈值、数据库文件等。 |
| database.py | 初始化 SQLite 数据库，提供保存传感器数据、保存报警记录、查询数据接口。 |
| sensor_publisher.py | 每2秒生成随机温湿度（温度15-35℃，湿度30-80%），通过 MQTT 发布。 |
| camera_publisher.py | 自动（每10秒30%概率）或手动（响应 MQTT 请求）生成真实随机图片，并发布摄像头告警消息（含图片文件名）。 |
| subscriber.py | 订阅 MQTT 传感器主题和控制主题；执行规则引擎（温度>30℃或湿度<40%时生成环境警报）；接收控制指令（喂食器/空调）并执行模拟动作，发布状态反馈。 |
| web_server.py | 启动 Flask Web 服务，通过 SocketIO 实时推送数据；接收前端控制指令并发布 MQTT 控制消息；订阅状态反馈主题并推送给前端。 |
| dashboard.html | 前端页面：使用 ECharts 显示温湿度历史曲线，实时更新当前值，展示警报列表，显示最新抓拍图片，提供手动拍照按钮（带倒计时），以及喂食器、空调控制按钮，实时显示操作反馈。 |

## 🚀 快速开始

 1. 安装依赖

在终端（确保已激活你的 Conda 环境）执行：

```bash
pip install paho-mqtt flask flask-socketio eventlet pillow
推荐使用 paho-mqtt==1.6.1 以避免版本兼容问题。pillow 用于生成真实图片。

2. 运行系统
需要同时运行四个终端（每个终端都先 cd 到项目目录 petmonitor）：

终端	命令	作用
1	python subscriber.py	启动订阅端（接收数据、规则引擎、存数据库、执行控制）
2	python web_server.py	启动 Web 服务器（访问 http://127.0.0.1:5000）
3	python sensor_publisher.py	启动温湿度模拟器
4	python camera_publisher.py	启动摄像头模拟器（自动+手动拍照）
启动后，打开浏览器访问 http://127.0.0.1:5000。

⚙️ 规则引擎
高温警报：温度 > 30℃ 时触发。

低湿警报：湿度 < 40% 时触发。

摄像头告警：接收到摄像头主题消息（自动或手动拍照）时触发。

所有警报会存入数据库，并实时显示在网页上。

🖱️ 前端操作指南
最新抓拍：页面右侧显示摄像头最新生成的图片（自动更新）。

刷新摄像头：点击“📷 刷新摄像头”按钮，倒计时 10 秒，之后生成新图片并自动显示。

远程控制：点击“🍖 喂食器”、“❄️ 开空调”、“🔥 关空调”按钮，状态区域会显示“喂食成功”或“空调已开启/关闭”等反馈信息（模拟执行）。
